# Project Fungsi Sederhana Dart

## Deskripsi
Project ini merupakan tugas pemrograman Dart yang berisi implementasi function sederhana dari 3 topik, yaitu:
1. Topik Menyapa
2. Topik Kalkulator Luas Persegi
3. Topik Kalkulator Diskon

Setiap topik dibuat menggunakan 4 jenis function yang berbeda, yaitu:
- Function tanpa parameter dan tanpa return
- Function dengan parameter dan tanpa return
- Function tanpa parameter dan dengan return
- Function dengan parameter dan dengan return

---

## Penjelasan Program

### 1. Topik Menyapa
Program ini digunakan untuk menampilkan pesan sapaan.  
Terdapat beberapa function:
- Function yang langsung menampilkan sapaan
- Function yang menerima nama sebagai parameter
- Function yang mengembalikan teks sapaan

Contoh output:
Halo

---

### 2. Kalkulator Luas Persegi
Program ini digunakan untuk menghitung luas persegi dengan rumus:

L = sisi × sisi

Terdapat function yang:
- Menggunakan nilai sisi langsung
- Menggunakan parameter sisi
- Mengembalikan hasil perhitungan

Contoh output:
Luas: 16

---

### 3. Kalkulator Diskon
Program ini digunakan untuk menghitung harga setelah diskon dengan rumus:

Harga akhir = harga - (harga × diskon / 100)

Function yang dibuat:
- Menggunakan nilai langsung
- Menggunakan parameter harga dan diskon
- Mengembalikan hasil perhitungan

Contoh output:
Harga setelah diskon: 90000

---

## Cara Menjalankan Program
1. Pastikan Dart sudah terinstall
2. Jalankan program dengan perintah:
   dart run dan ketik nama file nya

---

## Kesimpulan
Project ini membantu memahami konsep dasar function dalam bahasa Dart, terutama penggunaan parameter dan return value dalam berbagai bentuk function.
